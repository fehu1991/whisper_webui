# 本機即時收音與文字稿編輯

[回到專案首頁](../README.md) · [完整使用手冊](USER_GUIDE.md)


這項功能使用 WhisperLiveKit 0.2.26，在自己的電腦上接收麥克風聲音、持續辨識，並將確認後的文字加入原有的文字稿編輯工具。收音與編輯分成兩頁；切頁時收音繼續，人工修改不會被新辨識結果覆蓋。

## 會議前先完成安裝

1. 先完成原有 Whisper 工作台部署。從發布資料夾首次安裝時，執行 `DeployWhisper.cmd`。
2. 若使用 NVIDIA GPU，先透過 `WhisperTools.cmd` 安裝並驗證 CUDA 環境。只有 CPU 也能載入模型，但能否跟上現場語速必須實測。
3. 雙擊 `DeployLive.cmd`。這是會連網的安裝步驟，會安裝即時套件、準備 small 模型並檢查語音活動偵測模型，不會讀取錄音或逐字稿。沿用已下載的模型，不重複下載完整模型。
4. 關閉舊版工作台，重新雙擊 `RunWhisper.cmd`。點選頁首的「即時收音／文字稿編輯」。
5. 用非機密測試語音確認收音、辨識、修改、儲存及重新載入正常，再於斷網狀態重做一次。

安裝失敗時不要在會議現場反覆嘗試下載。先保留錯誤訊息，另找時間處理。啟動程式只使用本機套件和模型，不會自動連網修復。

## 電腦與瀏覽器需求

- Windows 10／11 x64，64 位元 Python 3.11～3.13；本次開發環境為 Python 3.13.3。其他版本尚未逐一實測。
- 使用支援 AudioWorklet 與麥克風授權的桌面 Edge 或 Chrome。請由 `RunWhisper.cmd` 開啟本機網址，不要直接雙擊即時頁的 HTML。
- 首次安裝要有網路與足夠磁碟空間；即時套件另含 PyTorch 等依賴。若尚未安裝 GPU 環境，請依主說明保留足夠空間。
- 模型由小到大為 base、small、medium、large-v3。先用 small 測試；顯示記憶體不足或辨識持續落後時，改用較小模型。
- 即時模式使用 WhisperLiveKit 的 faster-whisper／LocalAgreement，裝置與計算精度由引擎自動選擇，實際值顯示於收音狀態。不沿用音檔轉錄頁的「辨識細節精度 10」。
- 本機頁面可隨視窗縮放；原有音檔轉錄頁仍以 1280 px 以上桌面視窗為主。這不是手機錄音方案。

## 現場操作

1. 在「即時收音」頁選麥克風、模型及語言。中文會議先選中文，避免自動判斷錯誤。
2. 決定是否勾選「另外保留原始錄音」。預設不儲存聲音；勾選後會在本機留下 WAV 錄音。
3. 按「開始收音」，允許瀏覽器使用麥克風。模型載入期間還不會送入音訊；看到「收音中」再開始正式內容。
4. 切到「文字稿編輯」頁。確認後的段落自動加入末尾，可直接改文字、說話者與時間。搜尋、取代、批次修改等原有工具保留於可展開區域。
5. 收音狀態與停止按鈕固定在頁首。結束時按「停止收音」，等待最後一句處理完成及「已儲存於本機」提示，再下載 TXT 或關閉頁面。

預覽會隨辨識更新，不代表最終結果。編輯頁收到的是已確認片段。說話者預設為「待標註」，**本版不會即時自動區分說話人**；可手動標註，或保留錄音後使用原有音檔轉錄及 pyannote 功能。

新辨識片段只附加，不會改寫舊行。移動、刪除或修改過的行也不會因重複收到片段而恢復原狀。TXT 保留「編號. [說話者] [開始時間 - 結束時間] 文字」格式，可用獨立文字稿工具再次編輯。

## 儲存與復原

每場收音建立獨立資料夾：`.whisper/live/工作編號/`。

| 檔案 | 內容 |
|---|---|
| `session.json` | 模型、時間、工作狀態與原始確認片段 |
| `edited.json` | 編輯後文字與已接收片段編號；修改後短暫等待即自動儲存 |
| `recording.wav` | 只有勾選保留錄音時才建立，16 kHz 單聲道 |

若瀏覽器意外關閉，重新開啟工作台，在「接續編輯本機文字稿」選擇紀錄，再按「載入文字稿」。會載入最後成功儲存的修改，並補上尚未送入編輯頁的確認片段。尚未確認的辨識預覽、未送達本機服務的修改可能遺失。

選擇「中文（繁體）」時，使用本機 OpenCC 字典轉成臺灣繁體字形，不做詞語在地化改寫；原始辨識文字仍保存在 `session.json`。人名與多音多義字仍須人工核對。「自動偵測」不強制轉換字形。

尚未建立收音場次時，單獨匯入 TXT 的內容不會自動存入工作紀錄，請使用編輯器下載 TXT。載入已有的場次後，修改才會自動儲存。

重新整理、關閉瀏覽器、電腦休眠、麥克風拔除或本機連線中斷都可能停止收音。切換工作台內的「即時收音／文字稿編輯」不會停止。不要把切頁誤當成關閉頁面；錄音中也不要前往原音檔轉錄頁。

原始片段和人工修改分開存放，修改文字不會刪除 `session.json` 的原始辨識內容。這些都是明文檔案，不會自動清除。完成工作後，請依組織規範保存或移除整場資料夾；不要只刪除匯出的 TXT。

## 保密範圍

- 執行時僅開放本機 `127.0.0.1`，不建立公開分享網址，也不提供雲端備援辨識。
- 套件啟用離線模式並停用使用統計。WhisperLiveKit 使用明確的本機模型路徑，停用預設會下載示範音檔的暖機步驟。辨識子程序另拒絕 Python 層的網路連線。
- 即時頁與編輯頁的程式、字型設定均為本機內容；瀏覽器政策限制頁面向外連線。本機 API 有來源與短期權杖檢查，不接受其他網站跨站操作。
- 錄音預設不存檔；但逐字稿會自動存入本機。沒有錄音檔不代表電腦完全沒有聲音痕跡，作業系統記憶體交換、備份及管理軟體仍須由組織控管。
- 不使用 localStorage。請避免在裝有不受信任擴充功能或雲端校稿功能的瀏覽器中處理機密文字；關閉瀏覽器的增強型雲端拼字檢查。
- `.whisper/`、轉錄輸出、模型、快取與日誌都排除於 Git。Git 忽略規則不會保護手動上傳、已追蹤檔案或雲端同步，發布前仍應檢查檔案清單。
- 原音檔頁的上傳／麥克風暫存集中於 `.whisper/gradio-temp`。關閉工作台後再依保留規範處理，不要於轉錄中刪除。

這些是程式的本機設計與防護，不等於資安認證，也無法取代磁碟加密、Windows 帳號權限、作業系統防火牆或組織的斷網設備政策。敏感會議建議使用受管控的專用電腦。

## 限制與驗收

- 同一個工作台程序同時只執行一項推論：音檔轉錄或一場即時收音。不要另開第二個工作台程序搶用同一張 GPU。
- 每場收音使用獨立辨識子程序，停止或中斷後結束程序以釋放模型。下一場需重新載入模型。
- 最後一句可能需要等待；收音停止後仍會排空已接收音訊。辨識落後超過 30 秒會中止並提示改用較小模型，避免無限制累積。
- 單場上限 6 小時；這是保護性限制，**不是已完成 6 小時穩定性測試的宣告**。
- small 與 large-v3 的中文品質、多人搶話、人名、噪音與實際延遲應以現場麥克風測試。原先離線音檔測試的正確率與耗時不能直接套用到即時模式。
- 自動儲存失敗時會提示。請使用編輯器「下載 TXT」保留畫面內容，確認磁碟空間與權限後再繼續。

本機開發測試包含既有功能回歸、串流結束、來源檢查、人工修改保護與瀏覽器分頁；非機密合成語音用於功能驗證，不作為準確率基準。

技術依據：[WhisperLiveKit](https://github.com/QuentinFuxa/WhisperLiveKit)、[Hugging Face 離線與使用統計設定](https://huggingface.co/docs/huggingface_hub/package_reference/environment_variables)。
